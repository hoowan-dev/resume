I also architected a multi-threaded, asynchronous path-planning and navigation API in C++ that operated reliably within a strict $<$1.5ms frame budget. Working across a large-scale multi-disciplinary codebase, I partnered directly with gameplay designers and technical animators to prototype features, iterate on gameplay feel, and build in-editor tuning tools and visual debuggers that accelerated authoring loops. When dense simulation scenarios introduced performance bottlenecks or regressions, I profiled runtime memory and compute across character evaluation graphs and spatial query sweeps to eliminate hitches and maintain frame stability.

In my current role at \textbf{EA Lifestyle}, I have continued bridging runtime C++ engineering and cross-disciplinary workflows---engineering a high-throughput Unreal Engine C++ plugin that exports runtime character trajectory, pose, and velocity data to populate motion-matching query databases, as well as building Maya/Python and PyTorch/ONNX authoring tools adopted across multiple internal EA studios. Beyond my studio work, I have built a custom C++ game engine (\emph{Hoowan Game Engine}) with an EnTT ECS and collision resolution pipeline, as well as a 3D first-person shooter (\emph{DoomSlop}) featuring hitscan weapon raycasting and radar minimap systems.

As an internal EA engineer with a deep appreciation for \emph{Apex Legends}' industry-leading movement and combat feel, I am excited about the opportunity to collaborate with Respawn's designers and engineers to deliver polished, scalable features for a live multiplayer audience. Thank you for your time and consideration, and I look forward to discussing how my experience can contribute to the \emph{Apex Legends} team.
